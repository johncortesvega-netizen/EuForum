# Accountable Identity Model

European Public Square uses an accountability-first post model:

> Name and country on every post. Photo optional. Private life protected.

This is not a hidden profiling system. The forum stores the records necessary to preserve the conversation: accounts, rooms, threads, posts, timestamps, visible receipts, language metadata, and review states.

It does not build ad profiles, political profiles, inferred-interest graphs, behavioral scores, or algorithmic personalization models.

## Public post header

Every post should show:

- display name;
- country;
- role, when relevant;
- optional photo/avatar;
- original language / reader language.

It should not show:

- address;
- exact location;
- ID document number;
- private email/phone;
- birthdate;
- hidden identity history;
- inferred political or behavioral profile.

## Core line

> The forum stores what is necessary to preserve the conversation, not to profile the person.

## Internet-health rationale

The model responds to spam, bots, propaganda, and anonymous manipulation without turning the platform into surveillance infrastructure.

> Verify enough to protect the square. Store little enough to protect the person.

## Sydney Protocol boundary

The Sydney Protocol does not verify identity, punish users, decide truth, or moderate posts. It clarifies only. Human moderation and evidence review remain separate, accountable layers.
