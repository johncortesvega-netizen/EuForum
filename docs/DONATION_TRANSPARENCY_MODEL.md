# Donation Transparency Model

European Public Square may accept optional donations to cover operating costs. The funding model must match the public-good posture: free use, no ads, no hidden data economy, and public spending receipts.

## Donation rules

- Donations are optional.
- Donations do not unlock posting power.
- Donations do not affect moderation.
- Donations do not affect ranking or visibility.
- Donations do not buy governance control.
- Donor names may be private unless a donor chooses public acknowledgment.

## Public spending receipts

A donation page should show:

- monthly server cost;
- domain cost;
- backup/security cost;
- translation/API cost if used;
- moderation/evidence-review support if paid later;
- total donations received;
- total spent;
- current reserve;
- public spending receipts.

## Spending receipt fields

- receipt_id;
- date;
- amount;
- category;
- reason;
- covered period;
- public note;
- proof available: yes/no.

## Boundary phrase

Free to use. Publicly funded where possible. Spending shown by receipts.
