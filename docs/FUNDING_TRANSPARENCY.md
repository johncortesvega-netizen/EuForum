# Funding Transparency

## Core rule

The forum should remain free to use.

Optional donations may support:

- server costs;
- domain costs;
- backups;
- security;
- maintenance;
- translation infrastructure;
- moderation support;
- evidence-review support;
- accessibility and infrastructure improvements.

## Donations must not buy

- moderation power;
- ranking power;
- speech power;
- governance power;
- protocol influence;
- visibility boosts;
- immunity from rules;
- special treatment in disputes.

## Public spending receipts

Donation and spending records should be visible enough for public trust while protecting unnecessary private details.

Suggested spending receipt fields:

- receipt ID;
- date;
- amount;
- category;
- vendor/type;
- reason;
- covered period;
- public note;
- proof available yes/no.

## Example monthly transparency summary

```text
Donations received: €184.20
Server: €24.00
Domain reserve: €2.00
Backups: €5.00
Security monitoring: €0.00
Translation costs: €0.00
Remaining reserve: €153.20
```

## Core line

Donations keep the lights on. Receipts show where the light money went.
