# Moderation Boundaries

## Default posture

Hard speech gets receipts. Direct harm gets boundaries.

The forum should not erase difficult, offensive, angry, political, controversial, or confusing language by default. Where possible, language should remain visible and answerable with context, prompts, replies, evidence notes, and receipts.

## Hard boundaries

Separate human moderation should handle direct harm and severe abuse, including:

- direct threats;
- doxxing/private data exposure;
- child exploitation material;
- incitement to violence;
- targeted harassment campaigns;
- illegal harmful instructions;
- severe safety emergencies;
- spam/bot flooding.

## Moderator actions

Moderators may need to:

- hide a post;
- lock a thread;
- request an edit;
- remove private information;
- suspend an account;
- escalate a safety issue;
- mark a thread under review.

Every serious moderation action should create a moderation receipt.

## Appeal principle

Moderation must remain appealable where legally and safely possible.

## Core line

The platform does not erase disagreement. It restricts direct harm.
