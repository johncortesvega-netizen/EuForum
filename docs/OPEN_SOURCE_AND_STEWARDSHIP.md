# Open Source and Stewardship

The recommended posture for European Public Square is open-source, public-interest, and officially stewarded.

## Open source direction

The code should be inspectable when stable enough. The project should avoid hidden moderation machinery, hidden profiling, and hidden ranking logic.

## Official stewardship

Open source does not mean no responsibility. The official project needs clear stewardship for:

- public promise;
- privacy posture;
- moderation boundaries;
- receipt requirements;
- donation transparency;
- Sydney Protocol clarify-only use;
- release management.

## Fork boundary

Forks may exist depending on the license, but they should not imply they are the official European Public Square unless authorized.

## Boundary phrase

Open code. Official stewardship. Public receipts.
