# Patch 03 — Composer + Posting Limits

Patch 03 makes the local prototype's slow-forum behavior more explicit.

## Added

- Pause checkbox before posting.
- 45-second demo cooldown after a local post.
- 3-posts-per-30-minutes session limit.
- Live posting-status updates.
- Live receipt preview while drafting.
- Pre-post clarity checklist.

## Product intent

The forum is not engagement-first. It is intentionally slower:

- no infinite posting loop;
- no rage-reply acceleration;
- no hidden behavioral profile;
- no algorithmic feed;
- no Sydney Protocol enforcement.

## Sydney Protocol boundary

The Sydney Protocol layer clarifies only. It may show context, evidence, translation, pressure, dignity, or repair prompts. It does not judge, rank, punish, censor, enforce, or decide truth.

## Storage boundary

All new drafts remain in browser/page memory only. Refreshing the page clears them.
