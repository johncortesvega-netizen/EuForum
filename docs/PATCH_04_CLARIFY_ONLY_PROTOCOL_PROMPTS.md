# Patch 04 — Clarify-Only Protocol Prompts

Patch 04 adds a local Sydney Protocol prompt layer to the raw-shell prototype.

## Scope

This patch adds structured clarification prompts for:

- strong integrity/evidence claims;
- pressure or urgency language;
- dignity or escalation risk;
- authority overclaim;
- mechanism gaps;
- visible evidence paths.

## Boundary

The Sydney Protocol layer clarifies only. It does not:

- decide truth;
- accuse anyone;
- judge intent;
- rank posts;
- punish users;
- censor content;
- enforce moderation.

Moderators and hard-boundary policy remain separate from protocol prompts.

## Receipts

Draft receipt previews now show:

- prompt label;
- category;
- explanation;
- boundary statement;
- matched terms where available;
- quote/example context note where detected;
- post hash;
- language.

## Non-goals

Patch 04 does not add backend storage, real login, real translation, real moderation, payments, identity integration, or public launch readiness.


Boundary phrase: No enforcement action.
