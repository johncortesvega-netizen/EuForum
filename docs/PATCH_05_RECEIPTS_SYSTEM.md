# Patch 05 — Receipts System

Patch 05 makes receipts a visible product primitive in the local prototype.

## Purpose

The European Public Square should be receipt-first, not trust-me-first. Receipts explain visible platform actions without creating a hidden behavioral profile.

## Added

- `data/receiptSystem.js`
- receipt bundles for draft previews
- visible receipt cards on local posts
- sidebar receipt ledger
- receipt types for:
  - post record
  - translation visibility
  - Sydney Protocol clarification prompt
  - moderation placeholder
  - donation placeholder

## Boundary

Receipts do not:

- decide truth;
- rank users;
- punish users;
- moderate content;
- hide posts;
- create hidden profiles;
- create ad or behavior graphs;
- replace human review.

## Key principle

> The post is the print. Receipts explain what happened around it. No hidden second profile.
