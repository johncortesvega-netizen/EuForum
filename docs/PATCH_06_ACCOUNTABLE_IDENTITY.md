# Patch 06 — Accountable Identity Display

Patch 06 updates the prototype around the locked identity posture:

> Posts show name and country for accountability. Photo remains optional. No hidden second profile is created.

## Added

- public identity line on post cards;
- name + country fields in the local composer;
- identity display receipt in the receipt bundle;
- accountable identity concept doc;
- privacy promise clarified: necessary conversation records are allowed; hidden profiling is not;
- roadmap updated for identity-ready, accountability-first forum design.

## Not added

- no backend;
- no login;
- no persistent account system;
- no real identity verification;
- no EU wallet integration;
- no moderation enforcement;
- no hidden tracking;
- no ad/personalization profile.

## Boundary

This is still a local prototype. Name/country are demo fields stored only in browser/page memory when posting locally.
