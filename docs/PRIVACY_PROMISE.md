# Privacy Promise

## Core rule

The post is the print. No hidden second profile.

European Public Square should store only what is needed to run the forum and keep it safe.

## The platform should avoid

- behavioral ad profiles;
- political profiles;
- interest graphs;
- shadow profiles;
- hidden personalization;
- engagement scoring;
- follower-ranking systems;
- unnecessary identity documents;
- unnecessary device fingerprinting;
- selling or sharing user data for advertising.

## Minimal conversation records

A working forum must preserve enough records to make threads and accountability possible. This is not the same as hidden profiling. A working version may need:

- account/login identifier;
- display name;
- country shown on posts;
- optional profile photo/avatar;
- post/thread/reply content;
- timestamps;
- room/thread structure;
- language metadata;
- visible receipts;
- minimal security logs;
- moderation/evidence-review records.

## Identity posture

Name and country for accountability. Private life protected.

Proof when needed, privacy by default.

If future European identity systems are integrated, the preferred model is attribute proof, not identity storage:

- verified human;
- verified adult;
- verified region;
- verified organization representative.

The forum should verify the necessary attribute, not store the person. Public posts show name and country, but the platform should not expose address, exact location, ID documents, birthdate, private contact details, or hidden identity history.
