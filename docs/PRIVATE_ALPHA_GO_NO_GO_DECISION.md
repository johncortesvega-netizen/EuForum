# Private Alpha Go/No-Go Decision

Use this after reviewing the session report and issue log.

## Go

Continue to another small invited session only if:

- smoke test passes;
- no unresolved high-severity privacy issue;
- no unresolved high-severity safety issue;
- testers understand this is not public launch;
- testers understand Sydney Protocol is clarify-only;
- appeals can be handled by humans;
- moderators can keep up with reports;
- donation transparency is not misunderstood as donor influence.

## No-Go

Pause if:

- direct harm cannot be handled safely;
- privacy boundaries are unclear;
- receipts fail to render or confuse everyone;
- appeal flow cannot be explained;
- moderation workload exceeds available humans;
- any part of the test suggests public launch before readiness.
