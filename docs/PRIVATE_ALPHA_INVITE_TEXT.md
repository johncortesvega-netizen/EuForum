# Private Alpha Invite Text

Subject: Invitation to test European Public Square private alpha

Hi,

You are invited to test a private alpha of European Public Square, a slower multilingual forum prototype for context before reaction.

This is a controlled invited test, not a public launch. The goal is to learn whether the core model is understandable:

- name + country accountability;
- original-language preservation;
- translation as a bridge;
- visible receipts;
- posting limits;
- human moderation;
- evidence/context notes;
- appeal flow;
- donation transparency without donor influence.

Please do not post private personal data, direct threats, illegal material, or anything you would not want visible to the invited test group.

We are testing the model, not asking you to trust it yet.

## What To Expect

- Some features are mock-only.
- No real donation/payment system is connected.
- No real translation provider is connected.
- Moderation and evidence review are prototype flows.
- Feedback must not become a hidden behavioral profile.

Thank you for helping test slowly and carefully.
