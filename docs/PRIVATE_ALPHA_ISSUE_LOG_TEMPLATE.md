# Private Alpha Issue Log Template

Use one row per issue.

| ID | Date | Reporter | Area | Severity | Description | Repro Steps | Expected | Actual | Owner | Status |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| A-001 | YYYY-MM-DD | Name | Posting / Receipts / Moderation / Appeals / Docs | Low/Med/High | Short issue | Steps | Expected result | Actual result | Owner | Open |

## Severity

- Low: confusing text, polish, minor layout issue.
- Medium: blocks a test task or creates serious confusion.
- High: privacy risk, safety risk, broken moderation/appeal path, or public-launch misunderstanding.

## Boundary

Issue reports are for improving the prototype. Do not turn issue reports into hidden behavioral profiles.
