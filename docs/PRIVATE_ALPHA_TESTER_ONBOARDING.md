# Private Alpha Tester Onboarding

Welcome to the European Public Square private alpha.

## What This Is

A small invited test of a public-interest forum prototype.

## What This Is Not

- Not a public launch.
- Not a finished social network.
- Not a news source.
- Not a moderation authority.
- Not a payment or donation system.
- Not automated moderation.

## What To Try

- Open rooms and threads.
- Read original and reader-language text.
- Create a test post.
- Look at the receipt bundle.
- Report a post.
- Open moderation status.
- Submit an appeal if available.
- Open the transparency page.
- Open the Alpha Pack.
- Leave feedback using the feedback form.

## Safety

Do not post:

- private personal data;
- direct threats;
- child exploitation material;
- illegal harmful instructions;
- targeted harassment;
- spam/flooding;
- anything you would not want visible to the test group.

## Privacy

The prototype should show name + country for accountability. It should not create hidden behavioral profiles.
