# European Public Square — Public Concept

European Public Square is a free, slower multilingual forum for Europe.

It is designed as a public-interest forum, not an engagement platform. The goal is to support accountable discussion with original-language preservation, translation as a bridge, visible receipts, posting limits, human review, and Sydney Protocol prompts that clarify only.

## Core promise

- Forum structure, not an algorithmic feed.
- Free to use.
- No ads.
- No data monetization.
- No hidden behavioral profile.
- Posts show name and country for accountability; photo is optional.
- Translation keeps the original visible.
- Posting limits reduce spam, rage loops, and addictive behavior.
- Sydney Protocol prompts clarify only.
- Human moderators handle hard-boundary cases.
- Evidence reviewers add source/context notes, not truth-throne verdicts.
- Donations may support server and operating costs, with public spending receipts.

## Public identity posture

The forum is built for accountable public discussion. A post shows the person’s display name and country. The platform should not expose private life: no address, phone number, exact location, ID document, birth date, or hidden profiling.

## Product stage

This is a prototype direction, not a public launch. The current build demonstrates forum structure, local drafts, receipts, accountable identity display, a backend skeleton, and minimal login support.
