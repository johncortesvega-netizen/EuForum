# Public Promise

European Public Square is intended as a free, slower multilingual forum for Europe.

## What it promises

- Free public participation within fair limits.
- Old-school forum structure, not an algorithmic feed.
- No ads.
- No data monetization.
- No hidden behavioral profiles.
- No infinite scroll.
- Posting limits against spam, addiction loops, and rage escalation.
- Original-language preservation.
- Translation as a bridge, not a replacement.
- Human moderation for hard boundaries.
- Evidence reviewers for source/context notes.
- Visible receipts for protocol prompts, moderation actions, evidence notes, donations, and spending.

## What it does not promise

- It does not restore society.
- It does not solve polarization.
- It does not certify truth.
- It does not replace human moderation.
- It does not replace journalism, courts, science, public institutions, or democratic process.
- It does not make the Sydney Protocol an enforcement authority.

## Core line

A public square should not sell attention. It should make speech slower, clearer, and more accountable.
