# Sydney Protocol: Clarify Only

## Core rule

The Sydney Protocol is a clarification layer, not an enforcement layer.

It may clarify:

- strong claims;
- missing evidence;
- translation caveats;
- pressure language;
- escalation risk;
- dignity risk;
- unclear authority claims;
- mechanism gaps;
- repair questions.

It must not:

- judge truth;
- rank posts;
- punish users;
- censor users;
- decide legitimacy;
- declare corruption;
- declare guilt;
- tell users what to believe;
- tell users how to vote;
- replace moderators;
- enforce hard boundaries.

## Example prompts

Allowed:

- Strong claim — what evidence supports it?
- Translation may miss tone — view original before judging intent.
- This reply may escalate — consider asking a clarifying question.
- This statement asks for trust but does not show a mechanism.
- This wording may reduce a group to a threat label.

Not allowed:

- This is false.
- This is corrupt.
- This person is dangerous.
- Remove this.
- Believe this.
- Vote this way.
- Punish this user.

## Separation of roles

| Layer | Role |
|---|---|
| Sydney Protocol | Clarifies only |
| Moderators | Enforce hard boundaries |
| Evidence reviewers | Add source/context notes |
| Posting limits | Reduce spam/addiction/rage loops |
| Users | Speak, question, clarify, appeal, repair |

## Core line

Let language happen. Make it answerable. Stop direct harm through separate moderation rules.
